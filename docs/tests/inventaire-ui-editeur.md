# Inventaire UI — lot éditeur, catalogue et fiche

Sources : `docs/design/style-guide.md` §4–6, maquettes 10.1–10.3, plans 0011–0013 et 0032, ADR 0015–0017 et 0040. Les règles du lot sont dans `/tmp/regles-tests-ui.md`.

Statut « Écrit, non exécuté » : scénario découvert par Playwright, résultat navigateur inconnu ; chaque fichier `ui-*.spec.ts` a un équivalent `.webkit.spec.ts`. Les fichiers `.shared.ts` contiennent les scénarios. Aucun test existant n'est compté vert sans exécution. Les lignes « À écrire » restent des lacunes, même si des tests préexistants couvrent partiellement des critères : notamment `editor.spec.ts`, `creation.spec.ts`, `catalogue.spec.ts` et `fiche.spec.ts` emploient parfois API/route/force, interdits pour ce lot. Les sources ne définissent pas de tri dans la maquette ou le plan catalogue ; le besoin est conservé comme question de couverture. La fiche est indiquée provisoire dans le plan 0012. Aucun comportement d'alerte à la sortie n'est imposé : ADR 0040 prévoit l'enregistrement au départ.
