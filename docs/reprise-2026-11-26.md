## 3. Chantier en cours — recette réelle Databricks (#112), à reprendre ici

**C'est le point de reprise actif.** Tu voulais tester le connecteur Databricks sur **Free
Edition** (serverless uniquement, pas de création de SQL warehouse). Tu disposais de : *server
hostname*, *workspace ID*, *HTTP path*, *PAT*. Le `warehouse_id` est le **dernier segment du HTTP
path** (`/sql/1.0/warehouses/<id>`). L'API `/api/2.0/sql/statements` fonctionne avec le warehouse
serverless et un PAT ; le workspace ID n'est pas nécessaire pour cet appel.

**Étape 1 — smoke test (token uniquement en variable d'env, jamais écrit) :**

```sh
export ATLAS_DATABRICKS_TEST_HOST='https://<server-hostname>'          # ajoute https:// si absent, sans chemin
export ATLAS_DATABRICKS_TEST_HTTP_PATH='/sql/1.0/warehouses/xxxxxxxx'  # HTTP path, tel quel
export ATLAS_DATABRICKS_TEST_TOKEN='dapiXXXXXXXX'                      # PAT
export ATLAS_DATABRICKS_TEST_WAREHOUSE="${ATLAS_DATABRICKS_TEST_HTTP_PATH##*/}"
echo "warehouse_id = $ATLAS_DATABRICKS_TEST_WAREHOUSE"                 # ne doit pas être vide

curl -sS -X POST "$ATLAS_DATABRICKS_TEST_HOST/api/2.0/sql/statements" \
  -H "Authorization: Bearer $ATLAS_DATABRICKS_TEST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"statement":"SELECT 1 AS ok","warehouse_id":"'"$ATLAS_DATABRICKS_TEST_WAREHOUSE"'","wait_timeout":"30s","disposition":"INLINE","format":"JSON_ARRAY"}'
```

Attendu : `"status":{"state":"SUCCEEDED"}`, `"result":{"data_array":[["1"]]}`. 401 = token ;
403 = pas d'accès au warehouse ; 404 = warehouse_id faux ; `PENDING`/`RUNNING` = warehouse froid,
relancer.

**Étape 2 — sonde pytest**, modèle `tests/test_rest_real.py` + recette GitHub #206 :
`core/tests/test_databricks_real.py`, marqueur `databricks`, **sautée** sans les variables d'env,
**hors CI**. L'`AccessPoint` Databricks accepte déjà le `http_path` (sa méthode `warehouse()` en
extrait l'id) — la sonde se branche donc via `ATLAS_DATABRICKS_TEST_HTTP_PATH`, pas besoin d'un
warehouse_id séparé. Critères (plan mémoire `skifer-atlas/plan/databricks-recette`, local) :
`test()` (SELECT 1) ; une requête typée (entier, decimal, timestamp/timestamp_ntz, date, texte)
castée par `_value` ; borne `result_too_large` au-delà de `max_rows` ; jeton masqué dans un
message d'erreur (403/404) ; sautée sans env. L'installation de Skifer côté Databricks est **hors
Atlas** (cœur Skifer).
