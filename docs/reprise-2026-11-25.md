## 4. Consignes de travail

Ce sont les consignes de la mémoire de l'agent sur la machine précédente, recopiées ici parce que cette mémoire est locale.

- **Langue :** réponses en français. Les questions ouvertes se posent en texte, sous forme de liste numérotée avec une recommandation, pas par formulaire.
- **Répartition :** Codex code les correctifs et les features, et l'agent Claude orchestre (brief, relecture du diff, suites, PR, fusions). Les tests Playwright sont écrits par un agent Claude, pas par celui qui a codé.
  - Commande Codex : `codex exec -m gpt-6.1-terra -c model_reasoning_effort="high" -s workspace-write --add-dir ~/.cache/uv --add-dir /private/tmp -C <worktree> -o <sortie.md> - < <brief.md>`.
  - Pour relancer une session : `codex exec resume <id>`. L'identifiant se trouve avec `grep -m1 -i "session id" <journal>`.
  - Dans le bac à sable Codex, les sockets locaux et le réseau sont refusés. Les tests OAuth et de ports, mutmut et `npm ci` se relancent donc hors bac à sable.
- **Pas de chantier suivant tant que ses tests ne sont pas verts.** Chaque geste d'écran a un test Playwright qui fait le vrai geste. Les docs font foi : un écart reste un test rouge, jamais adapté au code. Les gestes sensibles au moteur ont aussi une version `*.webkit.spec.ts`. Un correctif s'accompagne d'un test qui échoue sans lui, et cet échec est vérifié en retirant temporairement le correctif.
- **Pas de recette manuelle :** les tests Playwright fonctionnels et les parcours de bout en bout font foi. Ne pas lancer `tauri dev` pour une recette. La navigation au clavier n'est pas prioritaire : les cas WebKit concernés sont en `test.fixme`.
- **Fusion :** seulement sur une CI verte qui a tourné sur le main à jour (protection stricte, 8 contrôles obligatoires). Après chaque fusion, mettre les autres PR à jour et attendre leur CI. Ne jamais baisser un seuil de couverture.
- **Python :** avant chaque commit, lancer `uv run ruff check .` puis `uv run ruff check --preview --select E301,E302,E303,E305,E306 .` dans `core/`. Ne jamais appeler `monkeypatch.undo()`, qui défait `ATLAS_DATA_DIR` et `ATLAS_VAULT` : utiliser `monkeypatch.context()`. Ne jamais toucher au vrai dossier `~/Library/Application Support/skifer-atlas` ni au vrai trousseau.
  - Suite complète : `ATLAS_DATA_DIR=$(mktemp -d) ATLAS_VAULT=memory uv run pytest -q -p no:cacheprovider --ignore=mutants --cov=skifer_atlas`.
- **Playwright local :** les ports sont fixes, donc une seule suite à la fois sur la machine. Depuis `app/`, lancer `npx playwright test --project=chromium --reporter=line --workers=1 <fichiers>`, et faire de même avec `--project=webkit` pour les `*.webkit.spec.ts`.
- **Sécurité :** le serveur Python n'écoute que sur 127.0.0.1 et exige le token de session. Les tokens des plateformes ne vont qu'au coffre local ou dans une variable d'environnement, jamais dans le dépôt.
- **Git :** pas de `git stash` nu, et les décisions se consignent dans `docs/decisions/`. Le prochain numéro libre est **0070**.
- **Nuit et limite de session :** programmer un réveil à l'heure de levée de la limite, puis relancer les agents coupés.
